# 4. Fluxo de Contato — LLM

## Ligação → Ligação → Mensagem

Ao receber o lead no WhatsApp, o SDR segue o fluxo padrão de contato. O modelo é chamado de LLM (Ligação → Ligação → Mensagem). Cada passo deve ser registrado na planilha de controle.

1. **Ligação**

   Primeira tentativa de contato por ligação telefônica imediatamente após receber o lead.

2. **Ligação**

   Segunda tentativa por ligação caso o lead não atenda na primeira.

3. **Mensagem WhatsApp**

   Após duas ligações sem resposta, enviar mensagem de apresentação no WhatsApp.
