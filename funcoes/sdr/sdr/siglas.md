# Siglas

| Termo               | O que o SDR precisa aprender                                                                |
| ------------------- | ------------------------------------------------------------------------------------------- |
| Lead                | Potencial cliente que demonstrou interesse.                                                 |
| Inbound             | Lead que chega por iniciativa própria, como resposta a um anúncio ou formulário.            |
| Outbound            | Prospecção iniciada pela empresa para abordar potenciais clientes.                          |
| ICP                 | Ideal Customer Profile: perfil de cliente ideal para a operação.                            |
| Funil de vendas     | Etapas que uma oportunidade percorre até a conversão.                                       |
| Qualificação        | Verificação de aderência, necessidade, capacidade de investimento e condições para avançar. |
| Follow-up           | Continuidade do contato para avançar uma oportunidade ainda aberta.                         |
| Recontato           | Nova tentativa de contato com um lead que ainda precisa ser trabalhado.                     |
| Show-up             | Comparecimento à reunião agendada.                                                          |
| No-show             | Ausência do lead em uma reunião marcada.                                                    |
| Taxa de agendamento | Percentual de leads que se tornam reuniões agendadas, conforme o denominador definido.      |
| Taxa de conversão   | Percentual de oportunidades que avançam para determinado resultado, como venda.             |
| CPL                 | Custo por lead gerado.                                                                      |
| CAC                 | Custo de aquisição de um cliente.                                                           |
